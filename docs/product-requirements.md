# Product Requirements Document

# Plain Note 제품 요구사항 문서

## 1. 프로젝트 개요

Plain Note는 노션과 옵시디언이 어렵게 느껴지는 사용자를 위한 가벼운 클라우드 메모앱이다.

노션은 기능이 많고 무거워서 단순한 메모를 쓰기에는 부담스럽고, 옵시디언은 강력하지만 초기 설정, 마크다운, 볼트, 동기화 개념이 초보자에게 어렵게 느껴질 수 있다.

Plain Note는 복잡한 설정 없이 바로 메모를 작성하고, 클라우드를 통해 어디서든 접근할 수 있는 간단한 메모 경험을 제공하는 것을 목표로 한다.

---

## 2. 해결하려는 문제

### 2.1 기존 메모앱의 문제

- 노션은 **기능이 많아** 초보자가 처음 사용하기 어렵다.
- 노션은 **노트가 많아질수록 무겁게** 느껴질 수 있다.
- 옵시디언은 **초기 설정**과 **동기화 방식**이 어렵다.
- 사용자는 단순히 메모를 쓰고 싶은데, 도구 사용법을 먼저 배워야 하는 경우가 많다.
- 정리 체계를 처음부터 완벽하게 만들지 못하면 노트 관리가 부담스러워진다.

### 2.2 Plain Note가 해결하려는 문제

- 사용자가 **별도 설정 없이 바로** 메모를 쓸 수 있게 한다.
- **노트 작성**과 **조회 속도**를 가볍게 유지한다.
- **클라우드 저장**을 통해 여러 기기에서 접근할 수 있게 한다.
- 폴더, 태그, 검색을 통해 **복잡하지 않은 정리 방식**을 제공한다.
- 정리를 완벽하게 하지 않아도 **검색**으로 다시 찾을 수 있게 한다.

---

## 3. 대상 사용자

### 3.1 주요 사용자

- 노션이 너무 복잡하거나 무겁다고 느끼는 사람
- 옵시디언의 초기 설정이 어렵게 느껴지는 사람
- **가볍게 메모**하고 싶은 **대학생**
- 공부 내용을 간단히 정리하고 싶은 사용자
- 클라우드 동기화가 되는 **단순한 메모앱**을 원하는 사용자

### 3.2 초기 핵심 사용자

초기 버전에서는 다음 사용자를 중심으로 한다.

- 공부용 메모를 작성하는 **학생**
- 개인 지식 정리를 시작하려는 **초보자**
- 복잡한 기능보다 빠른 작성과 검색을 원하는 사용자

---

## 4. 제품 목표

Plain Note의 핵심 목표는 다음과 같다.

1. 사용자가 앱을 열고 바로 메모를 작성할 수 있다.
2. 작성한 메모가 클라우드에 저장된다.
3. 사용자는 다른 기기에서도 자신의 메모를 확인할 수 있다.
4. 메모는 폴더와 태그로 간단히 정리할 수 있다.
5. 사용자는 검색을 통해 원하는 메모를 빠르게 찾을 수 있다.
6. 앱은 노션보다 가볍고, 옵시디언보다 쉽게 사용할 수 있어야 한다.

---

## 5. 제품 원칙

### 5.1 가벼움

앱은 빠르게 열리고 빠르게 작성할 수 있어야 한다.  
불필요한 애니메이션, 복잡한 블록 시스템, 과한 기능은 초기 버전에 포함하지 않는다.

### 5.2 쉬운 사용성

사용자는 마크다운, 백링크, 데이터베이스 같은 개념을 몰라도 기본 기능을 사용할 수 있어야 한다.

### 5.3 단순한 정리

초기 정리 방식은 폴더, 태그, 검색으로 제한한다.

### 5.4 클라우드 접근성

사용자는 웹을 통해 어디서든 자신의 메모에 접근할 수 있어야 한다.

### 5.5 기능 과잉 방지

Plain Note는 노션처럼 모든 것을 할 수 있는 도구가 아니라, 메모 작성과 검색에 집중하는 도구를 지향한다.

## 7. 주요 사용자 흐름

### 7.1 메모 작성 흐름

1. 사용자가 로그인한다.
2. 새 메모 버튼을 클릭한다.
3. 제목과 본문을 입력한다.
4. 메모가 저장된다.
5. 메모 목록에서 작성한 메모를 다시 확인한다.

### 7.2 메모 검색 흐름

1. 사용자가 검색창에 키워드를 입력한다.
2. 앱은 제목과 본문에서 검색어를 찾는다.
3. 관련 메모 목록을 보여준다.
4. 사용자는 원하는 메모를 선택해 내용을 확인한다.

### 7.3 메모 정리 흐름

1. 사용자가 폴더를 만든다.
2. 메모를 폴더에 넣는다.
3. 메모 본문이나 입력 필드에서 태그를 지정한다.
4. 사용자는 폴더 또는 태그를 기준으로 메모를 찾는다.

---

## 8. 핵심 기능 설명

### 8.1 메모

메모는 Plain Note의 가장 기본 단위이다.

초기 메모는 다음 정보를 가진다.

- 제목
- 본문
- 생성일
- 수정일

### 8.2 폴더

폴더는 초보자에게 가장 직관적인 정리 방식이다.  
사용자는 메모를 폴더에 넣어 주제별로 정리할 수 있다.

### 8.3 태그

태그는 폴더보다 유연한 분류 방식이다.  
한 메모는 여러 태그를 가질 수 있다.

### 8.4 검색

검색은 Plain Note의 핵심 기능이다.  
사용자가 정리를 완벽하게 하지 않아도, 제목과 본문 검색을 통해 메모를 다시 찾을 수 있어야 한다.

### 8.5 클라우드 저장

모든 메모는 서버에 저장된다.  
사용자는 웹 브라우저를 통해 다른 기기에서도 자신의 메모를 확인할 수 있다.

---

## 9. 성공 기준

1차 MVP가 성공했다고 판단하는 기준은 다음과 같다.

- 사용자가 회원가입과 로그인을 할 수 있다.
- 사용자가 메모를 생성, 조회, 수정, 삭제할 수 있다.
- 메모가 서버에 저장되고 다시 불러와진다.
- 사용자가 폴더로 메모를 정리할 수 있다.
- 사용자가 태그로 메모를 분류할 수 있다.
- 사용자가 검색으로 메모를 찾을 수 있다.
- 기본적인 웹 화면에서 사용 흐름이 끊기지 않는다.
